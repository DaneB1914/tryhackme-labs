## Overview

This challenge focuses on foundational penetration testing skills including service enumeration, content discovery, and transitioning from web access to system-level access.

---

## Key Skills Practiced

- Network and service enumeration (Nmap)
- Web vulnerability scanning (Nikto)
- Directory and file discovery (Gobuster)
- Source code inspection
- Credential reuse
- Command execution via web interface
- Shell stabilization and basic privilege escalation

---

## High-Level Approach

- Enumerated exposed services and web application
- Discovered sensitive information through page source review
- Identified hidden paths and credentials via directory enumeration
- Gained authenticated access to a restricted portal
- Executed commands and transitioned to a system shell
- Located target files through filesystem enumeration

*(Specific commands, payloads, and flags are intentionally omitted.)*

---

## Why This Matters

These techniques form the foundation of many real-world penetration tests. While the scenario is intentionally simplified, the skills practiced here are directly applicable to initial access phases of assessments.
